# HYPER PC MARKET (Узбекистан) 🇺🇿

Полнофункциональный интернет-магазин комплектующих для ПК с ручным **Конструктором сборок**, автоматической **проверкой совместимости**, **интерактивной визуализацией сборки** и **калькулятором FPS в 20 самых тяжелых играх** (с поддержкой добавления новых игр).

---

## 🚀 Реализованный функционал (Этап 1: Рабочее Ядро)

### 1. 🗄️ База данных и Каталог
* **СУБД**: SQLite (`better-sqlite3`) с поддержкой режима WAL.
* **Категории**: Процессоры, Материнские платы, Видеокарты, Оперативная память, Накопители SSD/HDD, Системы охлаждения, Блоки питания, Корпуса.
* **Мультиязычность**: Полная поддержка двух языков — **Русский (RU)** и **Узбекский (UZ)**. Мгновенное переключение без перезагрузки страницы.
* **Валюта**: **Узбекский сум (UZS)** с аккуратным форматированием разрядов (`so'm` / `сум`).
* **Поиск и сортировка**: Поиск по названию, бренду, сокету, чипсету, фильтрация по категориям и сортировка по цене/популярности.

### 2. 🛠️ Конструктор ПК с интеллектуальной проверкой совместимости
* **8 слотов комплектующих**: CPU, Motherboard, Cooler, RAM, GPU, Storage, PSU, Case.
* **Движок валидации (`server/compatibility.js`)**:
  - ✅ **Сокет CPU и Материнской платы**: (например, AM5 с AM5, LGA1700 с LGA1700. При несовпадении блокирует сборку с ошибкой).
  - ✅ **Тип памяти RAM**: проверка поколений DDR4 vs DDR5.
  - ✅ **Форм-фактор**: плата ATX не позволит собраться в корпус Micro-ATX.
  - ✅ **Габариты видеокарты**: длина GPU сверяется с максимальным лимитом длины корпуса.
  - ✅ **Высота кулера**: башенный кулер сверяется с шириной корпуса, чтобы закрылось боковое стекло.
  - ✅ **Теплопакет (TDP)**: сверка мощности кулера с тепловыделением процессора.
  - ✅ **Энергопотребление (PSU)**: суммарный расчёт TDP всей системы + запас +30% для переходных пиковых скачков мощности.

### 3. 🖥️ Интерактивная визуализация сборки (`VisualCasePreview`)
* Интерактивный корпус с прозрачной панелью.
* При выборе деталей они **в реальном времени монтируются в свои посадочные места**:
  - Плата садится на заднюю стенку.
  - Процессор устанавливается в сокет.
  - Кулер загорается подсветкой и вращающимися вентиляторами.
  - Модули оперативной памяти заполняют слоты DIMM с RGB-переливом.
  - Видеокарта защелкивается в слот PCIe x16.
  - SSD NVMe монтируется в слот M.2.
  - Блок питания располагается в нижнем тоннеле с кабельной разводкой.
* Живая шкала потребления ватт (TDP) и индикатор совместимости.

## ⚡ Инструкция по запуску

Приложение уже запущено и готово к работе:
- **Открыть в браузере**: [http://localhost:5000](http://localhost:5000)

Команды управления:
```bash
# Запуск всего проекта (Backend + Frontend на порту 5000):
npm start

# Запуск в режиме разработки Frontend (с горячей перезагрузкой на порту 3000):
npm run dev:client
```
